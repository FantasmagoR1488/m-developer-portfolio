# M+ Developer — Portfolio Website

Персональний сайт-портфоліо M+ Developer. Поки що сайт не опублікований.

## Запуск у VS Code
1. Відкрийте папку `M_Developer_Website` через **File → Open Folder**.
2. Відкрийте `index.html` у браузері подвійним кліком через Провідник або використайте розширення **Live Server** у VS Code.
3. Редагуйте HTML у `index.html`, стилі у `style.css`, поведінку у `script.js`.
